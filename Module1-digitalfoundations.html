📊 Week 2: GA4 Fundamentals & Google Tag Manager Setup

Learning Objectives:

  • Understand GA4's event-based tracking model
  • Set up a GA4 property and configure data collection
  • Implement Google Tag Manager (GTM)
  • Configure event tracking for key user interactions

📊 Exercise 2.1: GA4 Property Setup

Objective: Create and configure your first GA4 property

Task: Follow these steps:

  • Log into Google Analytics 4 (or create account)
  • Create a new Property (name it "Learning Property - [Your Name]")
  • Set up Web stream data collection
  • Copy your Measurement ID (starts with G-)
  • Document the property name and measurement ID
  • Explore the GA4 interface - familiarize with Reports, Explore, Admin sections

Deliverable: Screenshot of your GA4 property with Measurement ID visible

Due: Before the next session

🏷️ Exercise 2.2: GTM Container Setup

Objective: Create and configure Google Tag Manager

Task: Follow these steps:

  • Log into Google Tag Manager (or create account)
  • Create a new Container (Account and Container name)
  • Select "Web" as the target platform
  • Copy the GTM Container ID (starts with GTM-)
  • Copy the implementation code snippet
  • Review the GTM workspace interface

Deliverable: Screenshot of GTM Container creation with Container ID visible

Due: Before the next session

📈 Exercise 2.3: Event Tracking Configuration

Objective: Set up event tracking in GTM for key user interactions

Task: Research and document how to track these 5 events:

  • Button Clicks: When users click a CTA button
  • Form Submissions: When a contact/signup form is submitted
  • Video Plays: When video content starts playing
  • Scroll Depth: How far down the page users scroll
  • PDF Downloads: When users download resources

For each event, document:

  • Event trigger (what causes it)
  • Event parameters (data captured)
  • GTM trigger configuration needed
  • GA4 event name to use

Deliverable: Document with event tracking specifications

Due: Before the next session
